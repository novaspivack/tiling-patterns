Interaction mode

Paint: drag to color individual cells. Place: click the grid to drop the selected seed pattern there (hover highlights the target cell).

Neighborhood

Switching neighborhoods applies that neighborhood's default preset — a rule number means a completely different rule under a different neighborhood, so old rules don't carry over as-is.

Manual rule editor

Advanced rule view

The rule table is one row per color — everything that decides what happens to a cell currently in that color. Pin a color to freeze its row, then Randomize (or the per-row ▲/▼) only touches the colors left unpinned — e.g. pin one color to keep it clumpy while varying the rest to make them mobile. Reset a color to 0, then increment it a little at a time to find the critical point where its behavior changes.

Stats
